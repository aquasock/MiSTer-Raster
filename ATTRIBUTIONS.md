# Raster source attributions

This document records the provenance and licensing of third-party and reused
source included in the MiSTer-Raster FPGA project. It complements, and does not
replace, the copyright and license headers in individual files.

## Project code

Original Raster code retains its GPL-2.0-or-later licensing and `LICENSE.txt`.
Existing MiSTer framework and vendor files retain their individual copyright
and license notices. Framework files include GPL-3.0-or-later components, so
the combined design follows GPL-3.0-or-later.

The relevant full license texts are included as:

- `COPYING` — GNU GPL version 3
- `LICENSE.txt` — GNU GPL version 2, the baseline license for original project code
- `COPYING.LESSER` — GNU LGPL version 3 (for `sys/sd_card.sv`, below)

### Compatibility with MiSTer-Phosphor

MiSTer-Raster and MiSTer-Phosphor both license their original project code as
GPL-2.0-or-later, so code owned by the projects can move between them under the
shared terms. When that code is incorporated into a complete design containing
GPL-3.0-or-later MiSTer framework modules, GPL's "or later" option permits the
combined work to be distributed under GPL version 3 or later. Reuse does not
change the licenses on existing framework or vendor source.

## Code reused from MiSTer-Phosphor

The TAR/M3U implementation was adapted from MiSTer-Phosphor commit
`4b2a360347b6cef7ebbb73219edc18bc4f03294b`. The modules have since diverged; a
fix in one project is not automatically present in the other.

- `rtl/media_m3u_index.sv` and `rtl/media_playlist_resolver.sv` are adapted from
  the corresponding Phosphor modules, adding SRT stem resolution, optional
  matches and duplicate-match rejection.
- `rtl/media_album_ui_toggle.sv` reuses Phosphor’s I-key toggle, and
  `rtl/media_movie_playlist_ui.sv` adapts its `media_flac_album_ui.sv` renderer
  for a centered movie-title list after HDMI scaling.
- `rtl/media_tar_header.sv` follows Phosphor's `media_tar_index.sv` filename
  normalization and FNV-1a lookup scheme.
- `tools/media-builder/style.css` is Phosphor's shared builder style. Raster's
  builder follows the TAR utility's interface and archive arrangement, adding
  movie/SRT linking and a freestanding C/WASM header codec.

These Phosphor project files are GPL-2.0-or-later. Keep the notices and source
with redistributed builds and builder packages.

## MiSTer framework

The `sys/` tree is based on the standard
[MiSTer core framework](https://github.com/MiSTer-devel/Template_MiSTer). It
provides HPS communication, board integration, audio and video output, scaling,
OSD support, virtual storage, and related platform services.

Copyright holders named by the included framework files include:

- Till Harbaum

- Grabulosaure
- Mike Simone
- Kitrinx
- bellwood420
- Ultra-Embedded.com
- Other MiSTer framework contributors

The framework contains a license mixture that must be preserved file by file:

- GPL-2.0-or-later modules include `alsa.sv`, `arcade_video.v`, `audio_out.sv`,
  `iir_filter.v`, `ltc2308.sv`, `spdif.v`, `sys_top.v`, `video_freezer.sv`, and
  `yc_out.sv`.
- GPL-3.0-or-later modules include `ddr_svc.sv`, `hps_io.sv`, and
  `scandoubler.v`.
- `sd_card.sv` is LGPL-3.0-or-later.
- `hq2x.sv`, `video_cleaner.sv`, `video_freak.sv`, and `video_mixer.sv` identify
  themselves as GPL-licensed and retain their upstream notices.
- Other files in `sys/` remain part of the imported framework and retain their
  existing authorship or generated-code notices even where a per-file SPDX
  identifier is absent.

Do not remove or replace the copyright and license comments in these files when
updating the framework.

## Intel/Altera generated FPGA IP

PLL and PLL-reconfiguration sources generated by Quartus/Altera tools carry
Intel or Altera notices and are subject to the Intel FPGA software and IP
license terms embedded in those files. They are not relicensed by the project's
GPL declaration.

Relevant generated sources and support files include:

- `rtl/pll.v` and `rtl/pll/`
- `sys/pll_audio.v` and `sys/pll_audio/`
- `sys/pll_hdmi.v` and `sys/pll_hdmi/`
- `sys/pll_cfg/`
- Associated `.qip` files and generated configuration data

Those notices restrict the generated material to the uses permitted by the
applicable Intel FPGA license agreements. Keep the generated headers intact.

## Media builder

The converter recipe and workflow are adapted from the owner's local
`MiSTer-Raster_OLD/tools/phosphor_mpg_builder` (GPL-2.0-or-later project code).
The app downloads pinned ffmpeg.wasm wrapper/core distributions from unpkg
on demand; those binaries are not bundled in this repository or builder ZIP.
See the [ffmpeg.wasm project](https://github.com/ffmpegwasm/ffmpeg.wasm) and its
[licensing FAQ](https://ffmpegwasm.netlify.app/docs/faq/) for wrapper and core
licensing/source provenance.

## Redistribution checklist

When publishing source or an RBF release:

1. Include `COPYING`, `LICENSE.txt`, `COPYING.LESSER`, and this document with the
   corresponding source distribution.
2. Preserve all per-file copyright, license, and generated-IP headers.
3. Make the complete corresponding FPGA source used for the RBF available under
   the applicable licenses.
4. Record the MiSTer framework revision when importing future `sys/` updates.

This inventory documents the repository as audited; it is not legal advice.

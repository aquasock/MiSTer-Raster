    Playback and privacy

    Load the TAR in Raster. M3U order controls playback, N/P selects the next or previous movie, and the last movie loops to the first. Linked subtitles load automatically; use Subtitles → Visible in the core menu to turn them on or off. Movies without an SRT have no captions.

    The archive contains a standard playlist.m3u, original MPG files and optional matching SRT files. Files are copied without transcoding or modification. The builder accepts up to 255 movies, with each member smaller than 8 GiB. Use ordinary uncompressed USTAR; compressed TAR, PAX and GNU extensions are not supported. Existing playlists can be reopened and edited. No files are uploaded.

    Use your installed FFmpeg for native conversion. This command follows the frame rate, aspect ratio and quality above. Browser conversion always uses one thread.

    Run from the source file's folder, or enter full paths above. The browser cannot see the source's full path. Existing output files will not be overwritten.

    Convert all videos in a folder

    Copy this command and run it in your videos folder using Bash or a POSIX shell (Linux, macOS or WSL). It uses the selected frame rate, aspect ratio, quality and thread count. Install FFmpeg and ffprobe first.

    Converts video files in the current folder, including hidden files, into a Raster subfolder. Subfolders and files without video are skipped. Original extensions are kept in output names (movie.mp4 → Raster/movie.mp4.mpg) to avoid name collisions. Existing outputs are skipped.

    Conversion downloads the FFmpeg WebAssembly engine on first use and requires an internet connection. Files are never uploaded. Encoding runs on one CPU thread; long videos need substantial browser memory and may be better converted with native FFmpeg. The Playlist TAR tab works offline.
